# キッズゲームセンター (Kids Game Center)

子供向けの楽しいウェブゲーム集です。10種類のミニゲームで遊べます。

## 遊び方 (How to Play)

1. このフォルダでターミナルを開きます。
2. 以下のコマンドを実行してサーバーを起動します。
   ```bash
   python3 -m http.server
   ```
3. ブラウザで `http://localhost:8000` にアクセスします。
4. メニューから好きなゲームを選んでください。

**注意:** すべてのゲームは横画面（ランドスケープモード）で遊ぶように作られています。

## ゲーム紹介

### 1. スターキャッチャー (Star Catcher)
- 夜空に現れる星をつかまえるゲームです。

### 2. ふうせんワリ (Balloon Pop)
- 下からふわふわ上がってくる風船をタッチして割りましょう！

### 3. もぐらたたき (Whack-a-Mole)
- 穴からひょっこり顔を出すもぐらをタッチして捕まえてください。

### 4. えあわせ (Memory Match)
- カードをめくって、同じ動物の絵のペアを見つける記憶ゲームです。

### 5. よけろ！ (Dodge It)
- 画面をタッチしてキャラクターを動かし、落ちてくるボールを避けてください。

### 6. おえかき (Drawing Pad)
- 自由にお絵かきができるキャンバスです。色を変えたり消したりできます。

### 7. さんすうクイズ (Math Quiz)
- 簡単な足し算の問題が出ます。正しい答えを選んでください。

### 8. まるばつゲーム (Tic Tac Toe)
- 3つ並べたら勝ち！コンピュータと対戦する〇×ゲームです。

### 9. いろあて (Color Match)
- 「あか」「あお」など、文字で書かれた色と同じ色のボタンを探して押してください。

### 10. かたちあて (Shape Clicker)
- 画面を動き回る形の中から、「まる」「しかく」「さんかく」の指示通りのものをタッチしてください。

Enjoy playing!
