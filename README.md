# Kids Games Collection (キッズゲームコレクション)

子供向けのシンプルで楽しいウェブゲーム集です。10種類のゲームから好きなものを選んで遊べます！

A collection of 10 simple and fun web games for children. Choose your favorite and play!

## ゲーム一覧 (Game List)

1. **Star Catcher (スターキャッチャー)**: 夜空の星をタッチして捕まえよう！
2. **Fireworks (花火)**: 画面をタッチして花火を打ち上げよう！
3. **Scribble (おえかき)**: 指で自由にお絵かきしよう！（マルチタッチ対応）
4. **Piano (ピアノ)**: 8鍵盤のピアノで音を鳴らそう！
5. **Bubble Wrap (プチプチ)**: プチプチを潰す感触を楽しもう！
6. **Whack-a-Mole (モグラたたき)**: 出てくるモグラをタッチして叩こう！
7. **Raindrops (雨の波紋)**: 水面をタッチして波紋と音を楽しもう！
8. **Space Dodge (宇宙飛行)**: 岩に当たらないようにロケットを操作しよう！
9. **Fruit Catch (フルーツキャッチ)**: 落ちてくるフルーツをタッチしてキャッチしよう！
10. **Bouncing Ball (ボール弾き)**: ボールをタッチして弾き飛ばそう！

## 遊び方 (How to Play)

1. **ゲームを開く**: ブラウザでランチャーページを開きます。
2. **横画面にする**: スマートフォンを横向きに置いてください。
3. **ゲームを選ぶ**: アイコンをタップして遊びたいゲームを選びます。
4. **戻る方法**: ゲーム画面左上の家のアイコン（🏠）をタップすると、メニューに戻れます。

## インストール方法 (Android)

より快適に遊ぶために、ホーム画面に追加することをお勧めします。

1. Chromeブラウザでページを開く。
2. メニュー（︙）をタップ。
3. 「ホーム画面に追加」または「アプリをインストール」を選択。
4. ホーム画面から「Kids Games」アイコンをタップして起動すると、全画面モードでプレイできます。

## プロジェクト規約 (Project Regulations)

- **Android対応**: 全てのゲームはAndroid ChromeのPWAとして動作し、インストール可能です。
- **完全無料**: 広告や課金要素は一切ありません。
- **横画面専用**: スマホを机に置いて遊ぶスタイルを推奨しています。
- **軽量**: 全てのゲームはバニラJSで記述されており、画像や重いライブラリを使用していません。

## 開発者向け情報 (For Developers)

### 実行方法
```bash
python3 -m http.server
# Access http://localhost:8000/
```

- `index.html`: ゲームランチャー
- `games/`: 各ゲームのディレクトリ
- `shared/`: 共通のスタイルとスクリプト
