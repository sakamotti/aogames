# あそびばこ

3〜4歳のこども向けの、ミニゲームがたくさん詰まった知育アプリです。
**外出先でオフラインで遊ぶこと**を前提に、**費用0円**で運用できるように設計しています。
既存のコードは全面的に作り直し、対象年齢・遊び方・技術構成をゼロから見直しました。

## 設計方針(なぜこう作ったか)

3〜4歳児が一人で(または親のスマホを借りて)外出先で使うことを想定し、以下を徹底しています。

- **「失敗」がない**: スコアやライフ、ゲームオーバーは一切なし。タップすれば必ず良いことが起きる、失敗しても何も起きない(やり直せる)設計です。
- **文字が読めなくても遊べる**: ボタンは絵文字と色だけで判断できます。ゲーム内の音声・効果音がヒントになります。
- **指1本〜マルチタッチ対応、的が大きい**: ボタンやタップ対象は最低56px以上。誤タップで詰むことがありません。
- **誤操作でアプリを閉じない**: ホームに戻るボタンは0.65秒**長押し**しないと発動しません(連打しても外に出ません)。
- **縦・横どちらでも遊べる**: 外出先ではスマホを縦に持つことが多いため、回転を強制しません。
- **音声・効果音は合成音**: 音声ファイルを一切使わず、Web Audio APIとブラウザ標準の音声合成(SpeechSynthesis)でその場生成しています。アプリの容量が増えず、著作権や素材コストもかかりません。
- **オフライン動作**: Service Workerで全ページを端末にキャッシュするので、電波が無い場所でも遊べます。
- **広告・課金・通信なし**: 外部通信や個人情報の送信は一切ありません(保護者の方も安心して渡せます)。

## 保護者の方へ

- 広告・アプリ内課金・外部通信は一切ありません。
- 遊んでいる最中に個人情報を入力する場面はありません。
- 音を消したいときは画面右上の 🔊 ボタンをタップしてください。
- ゲームをやめて選択画面に戻るには、画面左上の 🏠 ボタンを**少し長押し**してください(誤タップ防止のためです)。

## 公開方法(費用: 0円)

このアプリはビルド不要のプレーンな HTML/CSS/JS のみで構成されているため、**GitHub Pages に無料でそのまま公開**できます。

1. このリポジトリを GitHub にプッシュします。
2. リポジトリの **Settings > Pages** を開きます。
3. **Source** で `Deploy from a branch` を選び、公開したいブランチと `/ (root)` を選択して **Save** します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

パスはすべて相対パスで書かれているため、ドメイン直下でもサブディレクトリ(GitHub Pagesのプロジェクトページ)でもそのまま動作します。

## Android への導入(費用: 0円)

### 方法A: ホーム画面に追加する(PWA、推奨・完全無料)

Google Play への登録は不要です。

1. Android の Chrome で公開した URL を開きます。
2. メニュー(⋮)から「ホーム画面に追加」または「アプリをインストール」をタップします。
3. ホーム画面のアイコンから起動すると、アドレスバーの無い全画面アプリとして動作します。
4. 一度開けば Service Worker が内容をキャッシュするので、以降は**電波が無くても**遊べます。

### 方法B: Google Play にアプリとして公開したい場合(任意)

無料の [PWABuilder](https://www.pwabuilder.com/)(Microsoft製)にサイトの URL を入力すると、このPWAをラップした Android パッケージ(AAB/APK)を無料で生成できます。生成したAPKは**サイドローディング(直接インストール)なら完全無料**です。Google Play ストアに掲載したい場合のみ、Google Play Console の登録料(一度きり US$25)が別途かかります。外出先での利用が目的であれば方法Aだけで十分です。

## 開発者向け情報

### ローカルで動かす

```bash
python3 -m http.server 8000
# http://localhost:8000/ にアクセス
```

ビルドツール・npm install は不要です(依存パッケージ0個)。

### ディレクトリ構成

```
index.html          # ホーム画面(ゲーム選択)
manifest.json        # PWAマニフェスト
sw.js                 # オフラインキャッシュ用 Service Worker
icons/                # アプリアイコン(コード生成、tools/generate-icons.js参照)
shared/
  style.css          # 共通デザインシステム(3〜4歳向けUIルール)
  app.js             # 共通ロジック(効果音合成/音声読み上げ/紙吹雪/ホームボタン/SW登録)
games/
  <game-name>/
    index.html
    script.js
tools/
  generate-icons.js   # 外部ライブラリ無しでPNGアイコンを生成するスクリプト
```

### 新しいゲームの追加方法

1. `games/<slug>/` フォルダを作り、`index.html` と `script.js` を追加します。
2. `<head>` で `../../shared/style.css` を読み込み、`<body>` の最後で `../../shared/app.js` → 自分の `script.js` の順に読み込みます。
3. `script.js` の先頭で `KidsApp.initCommon();` を呼ぶと、ホームボタン・ミュートボタン・Service Worker登録が自動で入ります。
4. 効果音は `KidsApp.Sound.pop()/chime()/success()/boing()/splash()/whoosh()/tap()`、読み上げは `KidsApp.speak('わんわん')` が使えます(いずれも追加ファイル不要)。
5. `index.html`(ホーム画面)の `.game-grid` にタイルを1つ追加します。
6. `sw.js` の `PRECACHE_URLS` に新しいファイルパスを追加すると、オフラインでも新しいゲームが遊べるようになります。

### 設計ルール(新しいゲームを作るときのチェックリスト)

- [ ] スコアや失敗、タイムリミットで子どもを焦らせない
- [ ] タップ/ドラッグ対象は指より大きく(目安56px以上)
- [ ] 文字を読まなくても遊び方がわかる
- [ ] 何をタップしても、悪いことは起きない
- [ ] 縦・横どちらの向きでも崩れない
