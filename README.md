# Star Catcher (スターキャッチャー)

子供向けのシンプルで楽しいウェブゲームです。夜空に浮かぶ星をタッチして捕まえましょう！

A simple and fun web game for children. Tap the stars floating in the night sky to catch them!

## 遊び方 (How to Play)

1. **ゲームを開く**: ブラウザでゲームを開きます。
2. **横画面にする**: スマートフォンを横向きに置いてください。（縦向きの場合は警告が表示されます）
3. **星をタッチ**: 画面の下から星が浮かび上がってきます。星をタッチすると「ポン！」と弾けてスコアが増えます。
4. **エンドレス**: ゲームオーバーはありません。好きなだけ星を捕まえて遊んでください。

## プロジェクト規約と技術選定 (Project Regulations & Compliance)

このプロジェクトは、以下の要件（規約）を遵守して作成されました。

### 1. Androidで動かせること (Works on Android)
- **実装**: HTML5, CSS3, JavaScript (Canvas API) を使用したプログレッシブウェブアプリ (PWA) として実装しました。
- **Android対応**: AndroidのChromeブラウザでネイティブアプリのように動作します。「ホーム画面に追加」を行うことで、全画面で楽しむことができます。

### 2. お金がかからないこと (No Cost)
- **実装**: 外部の有料アセットやライブラリは一切使用していません。
- **詳細**:
  - 画像素材は使用せず、Canvas APIで描画しています。
  - 音声はWeb Audio APIを使用してリアルタイムに合成（シンセサイズ）しているため、音声ファイルも不要です。
  - 完全に無料の技術スタックで構成されています。

### 3. 横画面で遊べる（スマホを置いて遊べる事） (Playable in Landscape)
- **実装**: CSSメディアクエリとPWAマニフェストを使用して、横画面（ランドスケープ）モードを推奨・強制しています。
- **詳細**:
  - `manifest.json` で `orientation: "landscape"` を指定。
  - 縦画面時には「画面を横にしてください」というメッセージを表示し、スマホを置いて安定した状態で遊べるように設計されています。
  - マルチタッチに対応しており、複数の指で同時に星をタッチできます。

## インストール方法 (Android)

より快適に遊ぶために、ホーム画面に追加することをお勧めします。

1. Chromeブラウザでページを開く。
2. メニュー（︙）をタップ。
3. 「ホーム画面に追加」または「アプリをインストール」を選択。
4. ホーム画面からアイコンをタップして起動すると、全画面モードでプレイできます。

## 開発者向け情報 (For Developers)

### ディレクトリ構成
- `index.html`: ゲームのメインエントリーポイント。
- `style.css`: ゲームのスタイルと横画面制御。
- `script.js`: ゲームロジック（描画、物理演算、音声合成）。
- `manifest.json`: PWA設定ファイル。

### 実行方法
ローカルサーバーを立ち上げて `star_catcher` ディレクトリにアクセスしてください。
```bash
python3 -m http.server
# Access http://localhost:8000/star_catcher/
```
